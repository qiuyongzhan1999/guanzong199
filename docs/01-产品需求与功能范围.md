# 01 · 产品需求与功能范围

> 2026-09-18 按最新口头需求收窄。领域说明见 [10-管综199与择校数据说明.md](./10-管综199与择校数据说明.md)。

## 1. 产品一句话

服务 **管理类联考（199 管综）+ 英语二** 考生：针对性刷题、查院校择校；写作/英语作文支持 **拍照 AI 批改**，并可选 **人工批改（加微信/企微）**。后期可用广告等变现。

## 2. 当前只要这四块（P0）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 针对性刷题 | 管综（数学/逻辑为主，写作练笔可选）+ 英语二题库；按知识点/题型练习 |
| 2 | 择校 | 智能择校（意向）+ 院校库；列表来自研招网；学费/招录来自简章与名单（见文档 11） |
| 3 | 搞清管综 199 | 产品文案、栏目、题型按大纲设计（见文档 10） |
| 4 | 批改 | 拍照/上传 → AI 批改（管综写作、英语作文）；人工批改 = 工单 + 加微信指引 |

## 3. 页面仍可对标参考图（壳）

| 模块 | 用途（按新范围） |
|------|------------------|
| 首页 | 入口：刷题、择校、AI 批改、人工批改、（可选）备考群 |
| 院校库 | 择校列表与筛选 |
| 我的 | 登录、我的练习、批改记录、加微信/客服、设置 |

不强制首版做：权益兑换、热度监测商业版、复杂 VIP（可后期 + 广告变现）。

## 4. 核心路径

```
打开小程序
  ├─ 刷题：选科目（管综数学/逻辑 / 英语二）→ 做题 → 看解析
  ├─ 择校：智能择校（选专业/地区）→ 列表 → 详情（学费/招录带来源链接）
  │         或直接进院校库搜校名
  └─ 批改：选「管综写作 / 英语作文」
        → 拍照或粘贴 → AI 出报告
        → 或选「人工批改」→ 生成说明 → 添加微信
```

## 5. 变现（当前只预留）

- 近期：刷题流量 → 广告（微信流量主等，需满足门槛）
- 中期：AI 批改次数 / 去广告会员
- 人工批改：按篇收费 + 加微信交付（高客单）

## 6. 明确不做（当前阶段）

- 用 AI 生成或「统计」冒充官方分数线/招生计划
- 完整在线机考考场、多考试方向（数一/法硕等）
- 重型 1v1 顾问排班系统（人工批改用微信即可）

## 7. 成功标准（先定性）

- 用户能按题型刷起来；择校字段有来源可核对
- AI 批改能跑通；人工入口加微信路径清晰
