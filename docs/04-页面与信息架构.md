# 04 · 页面与信息架构

对照参考图三 Tab；功能按当前范围：**刷题 + 择校 + 批改**。

## 1. 底部 Tab

| Tab | 路由建议 | 职责 |
|-----|----------|------|
| 首页 | `/pages/index/index` | Banner + 功能入口 |
| 院校库 | `/pages/schools/index` | 择校搜索/筛选/列表 |
| 我的 | `/pages/mine/index` | 登录、练习/批改记录、客服 |

> 刷题、批改从首页进，避免 Tab 过多。智能择校的页面结构以 [11-智能择校页面与数据来源.md](./11-智能择校页面与数据来源.md) 为准。

## 2. 全站页面树（当前范围）

```
Tab
├─ 首页 index
│   ├─ 刷题 practice（管综数学/逻辑、英语二）
│   │    └─ 练习页 / 结果解析
│   ├─ AI 批改 ai-essay（管综写作 / 英语作文）
│   │    ├─ 拍照上传 / 粘贴
│   │    ├─ 结果页
│   │    └─ 人工批改指引（工单号 + 加微信）
│   ├─ 智能择校 intent（专业 / 层次 / 地区）→ 结果列表 → 学校详情
│   └─ 备考群 / 客服（可选）
├─ 院校库 schools
│   └─ 院校详情 detail（字段带来源与年份）
└─ 我的 mine
    ├─ 登录
    ├─ 我的练习
    ├─ 批改记录
    ├─ 联系老师（微信/企微）
    ├─ 反馈、设置
    └─ （后期）会员 / 去广告
```

## 3. 首页宫格（建议）

| 卡片 | 副文案 | 跳转 |
|------|--------|------|
| 管综刷题 | 数学 · 逻辑 | 刷题-管综 |
| 英语二刷题 | 阅读 · 完形等 | 刷题-英二 |
| 智能择校 | 按专业 · 地区筛院校 | `pages/intent/index` |
| 院校库 | 搜校名 · 浏览 | 院校库 Tab |
| AI 批改 | 写作 / 英语作文 · 支持拍照 | AI 批改页 |
| 人工批改 | 加微信一对一 | 人工批改说明页 |
| 备考群（可选） | 资料交流 | 二维码 |

## 4. 院校库 + 智能择校

### 4.1 院校库 Tab

- 搜索校名；筛选：地区、层次（双一流/自划线）
- 列表卡片：logo、校名、地区、标签（无学费、无分数）
- 点进详情：与智能择校共用 `schools/detail`

### 4.2 智能择校（详见文档 11）

| 页 | 要点 |
|----|------|
| 选择意向 | 专业芯片（必选）→ 层次 → 地区多选 →「查看院校」 |
| 结果列表 | 标题显示已选专业/地区数；卡片同院校库 |
| 学校详情 | 头图 → 专业条 → 培养信息 → 分数 → 招录表 → 找老师核对 |

详情每一块数字旁：**年份 + 查看来源**。无简章数据则显示「待录入」，不造假。

## 5. 我的（对标图3）

- 头像与登录态
- 批改剩余次数（若已做配额）
- 菜单：智能择校、练习记录、批改记录、加老师微信、反馈、设置
- 后期再加：会员、兑换码
