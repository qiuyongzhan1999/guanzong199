# 08 · 数据模型草案

字段可在实现时微调；命名用 snake_case。  
择校粒度对齐 [11-智能择校页面与数据来源.md](./11-智能择校页面与数据来源.md)。

## 1. 用户

```text
users
  id, openid, unionid, nickname, avatar_url
  created_at, updated_at, last_login_at
```

## 2. 院校名片（研招网院校库）

```text
schools
  id
  sch_id              -- 研招网 schId，如 367866
  unit_code           -- 单位代码，如 10034（校徽路径用）
  name, province, city
  logo_url            -- https://t1.chei.com.cn/common/xh/{unit_code}.jpg
  is_double_first     -- 双一流（研招网标签）
  is_self_line        -- 自划线
  has_grad_school     -- 研究生院
  is_985, is_211      -- 我们静态打标，非研招网实时字段
  supervisor          -- 主管部门
  detail_url          -- 研招网院校详情
  brochure_list_url   -- 研招网「招生简章」列表入口
  status              -- online/offline
  updated_at
```

## 3. 招生项目（学校+专业+就读方式+年份）

一条记录对应详情页上的「一个专业条下的一种就读方式」。

```text
school_programs
  id, school_id
  year                -- 如 2026
  major_code          -- 125300
  major_name          -- 会计硕士
  study_mode          -- fulltime | parttime
  duration_years      -- 学制，可空
  tuition_per_year    -- 万元/年，可空；与全程二选一展示
  tuition_total       -- 全程万元，可空
  plan_exam           -- 统考计划人数，可空
  plan_recommend      -- 推免计划人数，可空
  exam_subjects       -- 如 "199,204"
  reexam_min_score    -- 本校复试最低分，可空
  nation_line_ref     -- 当年该专业国家线参考，可空
  source_url          -- 简章原文（必填才能展示学费等）
  source_name         -- 如「会计学院招生简章」
  checked_at          -- 人工核对日期；空=未核验不上架数字
  status              -- draft|published
```

## 4. 招录分析（可选，名单公布后填）

```text
admission_stats
  id, program_id, year
  reexam_count, admit_count
  note                -- 如「普通计划进入复试最低分 xxx」
  reexam_list_url
  admit_list_url
  source_name, checked_at

admission_score_bands
  id, admission_stat_id
  score_label         -- "256" 或 "250-254"
  score_min, score_max
  reexam_count, admit_count
  -- admit_rate 由前后端计算，不必落库
```

## 9. 关键查询

- 智能择校结果：`school_programs.major_code = ? AND checked_at IS NOT NULL AND status=published`，再按 `schools.province` / 层次过滤
- 详情专业条：同 `school_id` 下 published 的 distinct major
- 招录表：有 `admission_stats` 则展示，否则空态「本年名单未公布」
- 能否批改：`user_quotas.remaining > 0`（若已上配额）
