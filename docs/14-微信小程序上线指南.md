# 14 · 微信小程序上线指南

> 完整上线是**最后一步**。前面阶段用「开发者工具 + 本机/测试 API」就够。  
> 技术栈：uni-app 出小程序包 → Java API 挂 HTTPS 域名 → 微信后台配置 → 提审发布。

---

## 1. 上线前必须具备

| 条件 | 说明 |
|------|------|
| 小程序账号 | 建议**企业**主体；个人很多能力受限 |
| 已认证（企业） | 支付等能力需要 |
| 已备案域名 | API 必须是 `https://你的域名` |
| Java 服务已部署 | 公网可访问，HTTPS 正常 |
| 隐私政策 / 用户协议 | 小程序内可打开 |
| 类目选对 | 如教育类；按微信要求选，影响审核 |

个人主体：可先上线浏览 + 登录 + 内容；**微信支付往往做不了**，用兑换码/加微信收款过渡。

---

## 2. 开发期（不上线也能用）

```
在 HBuilderX 写代码，点「运行 → 运行到小程序模拟器 → 微信开发者工具」
  → 开发者工具详情里勾选「不校验合法域名」（仅开发）
  → 接口可先指向本机或内网穿透
```

真机预览：开发者工具生成预览码，手机微信扫。

---

## 3. 正式环境部署顺序

### 步骤 A · 服务器与域名

1. 买云服务器（或已有）+ 域名备案  
2. 安装 JDK、Nginx、MySQL（或云 RDS）  
3. 申请 SSL，Nginx 反代到 Java（如 `127.0.0.1:8080`）  
4. 浏览器访问 `https://api.xxx.com/actuator/health`（或你的健康检查）应 OK  

### 步骤 B · 微信公众平台配置

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 开发管理 → 开发设置：

1. 记下 AppID；AppSecret 重置后只放服务器  
2. **服务器域名** → request 合法域名：填 `https://api.xxx.com`（不要带路径）  
3. 若有上传：配置 uploadFile 域名（OSS 或你的上传域名）  
4. 业务域名（若内嵌 H5 协议页）按需配置  

### 步骤 C · 前端指向正式 API

1. uni-app 里把 `baseURL` 改成正式域名  
2. 发行 → 微信小程序 → 得到编译后的项目  
3. HBuilderX「发行 → 小程序-微信」后，在微信开发者工具里点上传（上传按钮只在这个工具里）  

### 步骤 D · 提审与发布

1. 开发者工具：**上传**，填版本号与备注  
2. 公众平台 → 版本管理 → 选版本 **提交审核**  
3. 按问卷填写：功能说明、测试账号（若需登录）、类目截图  
4. 审核通过 → **发布**  
5. 之后每次更新：再上传 → 审核 → 发布（可先体验版给内部）

---

## 4. 审核常见卡点（提前规避）

- 页面有「未完成」空壳、乱跳转  
- 未提供隐私协议却要登录/相册  
- 类目与内容不符（教育内容却选错类目）  
- 诱导分享、未说明的虚拟支付  
- AI 批改未说明「辅助学习、非官方阅卷」  
- 择校分数未标来源，被认作虚假宣传  

建议提审文案写清：数据来自研招网及院校公开简章；AI 结果仅供参考。

---

## 5. 上线当天检查清单

- [ ] HTTPS 证书有效  
- [ ] 合法域名已配且与代码 `baseURL` 一致  
- [ ] 微信登录在真机成功  
- [ ] 院校列表/详情能出数  
- [ ] AppSecret、DB、AI Key 不在前端包内（可抓包或查源码确认）  
- [ ] 体验版给 2～3 人试用无阻断 bug  

---

## 6. 和路线图的关系

| 阶段 | 和上线的关系 |
|------|----------------|
| 0～2 | 开发者工具即可，**不必**买域名 |
| 3～5 | 可用测试服 / 内网穿透 |
| 6 | 再按本文正式部署 + 提审 |

**结论：现在不用上线。** 等功能闭环、Java 稳定后，按本文 A→D 做；到那一步我会逐步盯着你填域名和后台配置。
