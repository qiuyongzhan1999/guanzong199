## 3. 密码怎么给我才安全

**可以：**

- 只发 AppID、域名、非机密配置
- 机密用本地文件：`server/src/main/resources/application-local.yml`（加入 `.gitignore`）
- 或你自己在服务器设环境变量，我只写「读哪个环境变量名」

**不要：**

- 把 AppSecret / 数据库密码 / API Key 提交到 git
- 把完整密钥贴进可被同步的公开文档
- 在群聊里反复转发密钥
