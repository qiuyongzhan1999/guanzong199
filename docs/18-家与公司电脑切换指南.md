# 18 · 家用电脑 ↔ 公司电脑 切换指南

换电脑开发时：**MySQL 连接地址一般不用改**；要改的是「项目落在哪」和「JDK 装在哪」这类本机路径，以及每台机器各自的密码/密钥文件。

---

## 一句话结论

| 事项 | 要不要改 | 说明 |
|------|----------|------|
| MySQL 主机/端口/库名 | **通常不用** | 固定连本机 `127.0.0.1:3306`，库名 `gz199` |
| MySQL 密码 | **可能要改** | 两台电脑若 root 密码不同，各自改本地脚本 |
| 项目数据目录 `data-dir` | **路径不同就要改** | 指向本机项目下的 `data` 文件夹 |
| JDK 路径 | **几乎一定要改** | 家/公司安装位置常不同 |
| DeepSeek Key | **每台单独配** | 不进 git，用本地密钥文件 |

---

## 当前仓库里写死的路径（对照表）

以「家」为 `D:\123\gz199`、「公司」若也是同一路径则 **data-dir 可不动**。

| 文件 | 硬编码内容 | 换电脑时 |
|------|------------|----------|
| `server/src/main/resources/application.yml` | `gz199.data-dir: D:/123/gz199/data` | 项目不在 `D:\123\gz199` 时改成新路径下的 `data` |
| `server/scripts/restart-backend.ps1` | `$root = "D:\123\gz199"` | 有回退逻辑；建议改成你本机真实根目录 |
| 同上 | `$jdkCandidates`（家 `D:\java\jdk-17`、公司 `E:\workTool\java\jdk-17` 等） | **一般不用改**；脚本会自动找。若两台都不在列表里，把本机路径加进 `$jdkCandidates` |
| `server/start-dev.ps1`（gitignore，不进仓库） | `$env:DB_PASSWORD`、日志路径 `D:\java\...` | **每台电脑各自新建一份** |
| `server/local-secrets.ps1`（gitignore） | DeepSeek Key 等 | **每台电脑各自新建一份** |

**不需要因为换电脑去改的：**

- `spring.datasource.url`（仍是 `jdbc:mysql://127.0.0.1:3306/gz199?...`）
- `utils/api.js` 里的 `http://localhost:8080`（前端连本机后端）

## 两台机器建议怎么填（模板）

在下面填好，换机时只对照改文件，不必再翻代码。

### 家用电脑

```
项目根目录:   D:\123\gz199
data-dir:     D:/123/gz199/data
JDK 17:       D:\java\jdk-17          ← 按你家里实际安装改
MySQL:        本机 3306 / 库 gz199 / 用户 root
DB 密码写在:  server\start-dev.ps1
API Key 写在: server\local-secrets.ps1
```

### 公司电脑

```
项目根目录:   ________________（例：D:\123\gz199 或 E:\work\gz199）
data-dir:     ________________/data   （正斜杠也行，如 E:/work/gz199/data）
JDK 17:       ________________        （例：E:\workTool\java\jdk-17）
MySQL:        本机 3306 / 库 gz199 / 用户 root
DB 密码写在:  server\start-dev.ps1
API Key 写在: server\local-secrets.ps1
```

> `restart-backend.ps1` 已自动探测 JDK（先看 `JAVA_HOME`，再试 `D:\java\jdk-17` 与 `E:\workTool\java\jdk-17`）。两边只要装在常见路径，**不用再手改第 17 行那种硬编码**。

## 换机检查清单（按顺序做）

### 1. 确认本机 MySQL 能用

- 服务已启动，库名 `gz199` 已建好（没有就执行 `server/sql` 里的建表脚本，见文档 13）。
- 密码记住：后面写进 `start-dev.ps1`。

### 2. 改数据目录（项目路径不同时）

打开：`server/src/main/resources/application.yml`

```yaml
gz199:
  data-dir: D:/123/gz199/data   # ← 改成「本机项目根/data」
```

只影响读本地 JSON（`data/`）；**不影响 JDBC 连库**。连库仍看同文件里的 `spring.datasource`。

### 3. JDK（一般不用改脚本）

`restart-backend.ps1` 会自动在下列位置找 JDK 17：

1. 环境变量 `JAVA_HOME`
2. `D:\java\jdk-17`（家用常见）
3. `E:\workTool\java\jdk-17`（公司常见）
4. Program Files 下常见 Temurin / Microsoft / Oracle 安装

启动时应打印一行绿色：`JDK: ...`。若报 not found，把本机路径加进脚本里的 `$jdkCandidates`。

验证：

```powershell
& "你的JDK路径\bin\java.exe" -version
# 应显示 17.x，不是 1.8
```

### 4. 本机密钥文件（每台各一份，不要互相覆盖提交）

**数据库密码** — 新建或编辑 `server/start-dev.ps1`（已在 `.gitignore`）：

```powershell
$env:DB_PASSWORD = '你的本机MySQL密码'
Set-Location $PSScriptRoot
mvn spring-boot:run
```

**DeepSeek** — 从示例复制：

```powershell
cd server
copy local-secrets.ps1.example local-secrets.ps1
# 编辑 local-secrets.ps1，填入 Key；可选再写 DB_PASSWORD
```

### 5. 启动并验收

```powershell
# 推荐：双击仓库根目录「重启后端.bat」，或：
.\server\scripts\restart-backend.ps1
```

浏览器打开：http://127.0.0.1:8080/api/health  

期望大致包含：`"mysqlReady": true`（库里有院校数据后）。

## 数据库：换电脑到底要不要「改路径」？

**不用改 JDBC 路径。** 两边都是：

```text
jdbc:mysql://127.0.0.1:3306/gz199
用户: root
密码: 环境变量 DB_PASSWORD（由 start-dev.ps1 / local-secrets.ps1 提供）
```

换电脑时真正要保证的是：

1. **本机已安装并启动 MySQL**
2. **本机已有库 `gz199` 和表**（数据不会自动跟着代码走；需要导入或从家里备份还原）
3. **密码与 `DB_PASSWORD` 一致**

数据迁移可选方式：Navicat/mysqldump 导出家里库 → 公司导入；或重新跑文档 13 的导入脚本。

## 最小改动一览（复制用）

| 场景 | 改哪个文件 | 改哪一行 |
|------|------------|----------|
| 项目不在 `D:\123\gz199` | `application.yml` | `gz199.data-dir` |
| JDK 不在常见路径 | `restart-backend.ps1` | 往 `$jdkCandidates` 里加一行本机路径 |
| MySQL 密码不同 | `start-dev.ps1` 或 `local-secrets.ps1` | `DB_PASSWORD` |
| 没有 DeepSeek 建议文案 | `local-secrets.ps1` | `DEEPSEEK_API_KEY` |
| 只连库、项目路径相同 | — | **可不改路径，只保证 MySQL + 密码** |
