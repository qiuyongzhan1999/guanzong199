# 11 · 智能择校页面与数据来源

> 页面参考你给的「选择意向 → 院校列表 → 学校详情」，**交互可以像，视觉不要做成同一套**。  
> 数据原则：能对上官网的才展示数字；对不上的留空或标「待核验」。**禁止用 AI 补分数线。**

---

## 1. 先纠正一个来源误会

你指定的这一页：

[研招网院校库](https://yz.chsi.com.cn/sch/search.do?ssdm=&yxls=&ylgx=&yjsy=&zhx=)

**只能提供列表和学校名片**，提供不了图 4、图 5 里的学费、学制、复试线、分数段录取表。

| 页面上看到的 | 这一页有没有 |
|--------------|----------------|
| 校名、省份、主管部门 | 有 |
| 「双一流」、研究生院、自划线 | 有 |
| 网报公告 / 招生简章 / 调剂办法 **入口链接** | 有（点进去才是正文） |
| 校徽图片 | 有（学信网图床，如 `https://t1.chei.com.cn/common/xh/10034.jpg`） |
| 985 / 211 勾选 | **没有**。现在官网主标签是「双一流」。985/211 要用教育部历史名单自己打标 |
| 某专业是否招生、考试科目 | **没有**。在 [硕士专业目录](https://yz.chsi.com.cn/zsml/) |
| 学费、学制、招生人数 | **没有**。在**该校当年招生简章**（学院或研究生院网站） |
| 复试线、复试人数、录取人数、分数段录取率 | **没有**。在该校研究生院的**复试名单 / 拟录取名单**，我们按分数段自己汇总 |
| 「2027 预测分 / 建议报考分」 | **任何官网都没有**。这是产品自己的估算，必须写「非官方」 |

国家线在研招网另一页，不在院校搜索页：[近五年分数线](https://yz.chsi.com.cn/kyzx/zt/lnfsx2026.shtml)。

## 2. 页面怎么走（三步，不照搬小鹿）

```
选择意向
  → 结果列表（可再搜、再筛）
    → 学校详情（按专业切换）
```

底部仍是：首页 / 院校库 / 我的。  
「智能择校」从首页或「我的」进入，结果页可以复用院校库列表组件。

### 2.1 选择意向（对照你的图，改交互）

参考图是：专业下拉 + 层次全勾选 + 省份方格 + 大蓝按钮 + 右下角「1v1」。

我们改成：

| 块 | 我们的做法 | 为什么不照抄 |
|----|------------|----------------|
| 专业 | 单选芯片，一行能看完，不要长下拉盖住后面 | 专业就十来个，下拉多余 |
| 层次 | 单选：不限 / 双一流 / 自划线。985、211 做成可选标签，默认不勾 | 研招网实时字段是双一流和自划线，不是 985 |
| 地区 | 芯片多选，带「全选」。已选数量写在标题旁 | 方格全空时看不出进度 |
| 主按钮 | 「查看院校」，没选专业时不可点 | 「下一步」太模糊 |
| 1v1 | 不做悬浮球。详情页底部一条「找老师核对」链到加微信 | 悬浮球挡表格 |

专业芯片与代码（都考 199 + 英语二，以当年简章为准）：

| 芯片文案 | 代码 |
|----------|------|
| 工商管理 MBA | 125100 |
| 公共管理 MPA | 125200 |
| 会计 MPAcc | 125300 |
| 旅游管理 | 125400 |
| 图书情报 | 125500 |
| 工程管理 | 125601 |
| 项目管理 | 125602 |
| 工业工程与管理 | 125603 |
| 物流工程与管理 | 125604 |
| 审计 MAud | 125700 |

筛选逻辑：专业必须选；地区、层次可空（空 = 不限）。

### 2.2 结果列表

和院校库同一套卡片，但标题写成「会计 · 已选 3 个地区」，方便返回改意向。

卡片只放**研招网能核对的**：校名、省、双一流/自划线、（若我们打过标）211。  
右边箭头进详情。没有学费、没有分数，避免列表上出现无来源数字。

### 2.3 学校详情（对照图 4、图 5）

一块一来源，数字旁边必须有**年份 +「查看来源」**。

1. **头图**：校名、省、标签。数据：院校库。
2. **专业条**：该校在管综范围内实际招生的专业（来自专业目录核验，不是写死两个 Tab）。
3. **培养信息**：学制、学费、全日制/非全、计划人数。数据：该校简章。没有简章就显示「简章待录入」，不显示假数字。
4. **分数**：国家线（研招网）和该校复试最低分（研究生院名单）分开两行，不要画成一条来路不明的折线。
5. **招录表**：分数段、进复试人数、录取人数、录取率。数据：我们用官方复试名单 + 拟录取名单汇总。表下写名单原文链接。
6. **报考参考（可选，后做）**：预测分。标题必须是「平台估算，非官方」，无数据就不做遮罩星星。
7. **页脚**：数据有误 → 反馈。人工核对 → 加微信（你们自己的老师，不是爬来的）。

图表可以后做。首版用数字和表格，比参考图那条只有一个点的折线更清楚。

## 3. 每个字段去哪个官网拿

维护时按这个表填，填完把「来源 URL」存进数据库，详情页可点开。

| 详情里的字 | 去哪拿 | 入口 |
|------------|--------|------|
| 校名、省份、双一流、自划线、主管部门 | 研招网院校库 | [搜索页](https://yz.chsi.com.cn/sch/search.do?ssdm=&yxls=&ylgx=&yjsy=&zhx=) |
| 校徽 | 学信网图床，院校库 img 已给出 | `https://t1.chei.com.cn/common/xh/{单位代码}.jpg` |
| 招生简章列表入口 | 院校库卡片上的「招生简章」 | 例：中财 `https://yz.chsi.com.cn/sch/listZszc--schId-367866,categoryId-10460824,mindex-13,start-0.dhtml` |
| 是否招这个专业、初试科目 | 研招网硕士专业目录 | [专业目录](https://yz.chsi.com.cn/zsml/) ，按专业代码筛招生单位 |
| 国家线（MBA/MPA/会计等总分） | 研招网分数线专题 | [近五年分数线](https://yz.chsi.com.cn/kyzx/zt/lnfsx2026.shtml) |
| 学制、学费、就读方式、招生计划 | **学校或学院当年简章正文** | 从研招网简章入口跳到学校站点；各校域名不同 |
| 复试最低分、复试名单 | **学校研究生院**复试通知 / 资格审查表 | 各校研究生院「硕士招生」栏目 |
| 录取人数、分数段、录取率 | 同上栏目的**拟录取名单**，和复试名单对分数后自己算 | 不存在「录取分析」这一官方接口 |
| 预测分、建议报考分 | 不爬。以后用历年复试分做区间，或人工 | 文案固定：「平台估算，不代表学校划线」 |

985 / 211：用一份静态对照（教育部公布的历史名单），挂在我们自己的标签字段上，不要写成「研招网实时返回」。

## 4. 例子：中央财经大学 · 会计（用来对图 4）

图里写过「学制 3 年、学费 10.2 万」。**2026 年学院简章不是这个数**，所以不能照着参考图填。

以学院简章为准：[中央财经大学 2026 年会计硕士和审计硕士招生简章](https://soa.cufe.edu.cn/info/1040/7765.htm)

| 项 | 简章写法（2026） | 我们怎么展示 |
|----|------------------|--------------|
| 专业 | 会计 125300；另有审计 125700 | 两个专业条，不要只做一个 Tab |
| 就读方式 | 会计：全日制 + 非全日制；审计：仅全日制 | 必须分开展示，不能合成一个学费 |
| 计划 | 非全会计统考普通计划 104；全日制会计统考普通计划 2（另有推免） | 写清楚「统考 / 推免」，否则用户会误判难度 |
| 学费 | 全日制会计、审计 3.4 万/年；非全日制会计 9.4 万/年 | 不要写成一个「10.2 万全程」 |
| 名单与复试安排 | 学院通知指向研究生院 | [研究生院硕士招生](https://gs.cufe.edu.cn/zsgz/sszs_sz_.htm) |
| 院校库名片 | 北京、「双一流」、单位代码 10034 | [研招网详情](https://yz.chsi.com.cn/sch/schoolInfo--schId-367866.dhtml) |

复试分数段表：等该年**复试名单 + 拟录取名单**公布后，按分数段计数。名单没挂出来之前，这块显示「本年名单未公布」。

## 5. 入库时一条记录长什么样

一条 = **学校 + 专业 + 就读方式 + 年份**。中财会计至少拆成「全日制」「非全日制」两行。

必填才能上线展示数字的：

- 学校、专业代码、就读方式、年份
- 学制、学费、计划人数
- `source_url`（简章或名单原文）
- `source_name`（例如「会计学院招生简章」）
- `checked_at`（我们核对的日期）

可空：

- 复试最低分、复试人数、录取人数、分数段 JSON
- 平台估算分（空则详情页不出现这一块）

## 6. 和现有表的关系

| 文件 | 内容 |
|------|------|
| `data/schools.json` / `catalog.json` | 院校名片、管综专业开设 |
| `data/nation_lines.json` | 国家线（全校按专业+年份） |
| `data/programs.json` / `admissions.json` | 已核对培养信息 / 招录 |
| `data/pipeline/` | 半自动：抓简章草稿 → 人工 `checkedAt` → promote（见其中 README） |

学费和招录不要塞进院校名片里硬凑一个数。
