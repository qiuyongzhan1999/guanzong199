## 2. 推荐工程目录（以后创建时用）

```
/apps/mini          # uni-app Vue3 前端
/server             # Spring Boot 后端
  /src/main/resources
    application.yml
    db/migration    # 或 sql/schema.sql
/docs               # 产品文档（已有）
/data               # Excel / JSON 样例数据（已有）
```

**写代码用 HBuilderX**（uni-app Vue3 官方 IDE）。VS Code 只是备选，你不用换。  
**微信开发者工具不是编辑器**：HBuilderX 点「运行到小程序模拟器」后，它负责预览、真机调试、上传代码。微信平台规定必须经过它，没法只用 HBuilderX 完成预览和上线。  
后端：JDK 17+、Maven 或 Gradle、IDEA。  
数据库：本地 MySQL 8，或云数据库（以后上线用）。

---

## 3. 和「uniCloud」的关系

你已定 **Java + MySQL**，就**不要**再用 uniCloud 当主后端，避免两套数据。  
uni-app 只负责小程序 UI，接口全部打你的 Java 域名。

---

## 4. 安全底线（全程遵守）

- 小程序 `AppSecret`、支付密钥、AI Key、数据库密码 → **只在 Java 配置 / 环境变量**
- 前端只有：AppID、你的 API 域名、用户登录后的 token
- 生产库账号不要用 root；应用账号只给需要的库权限

需要你提供哪些账号密码、什么时候提供：见 [12-账号密码与何时提供.md](./12-账号密码与何时提供.md)。
