# 15 · 项目目录说明 & Spring Boot 怎么连上 MySQL

面向：不太熟后端也能看懂。  
项目名：管综199（小程序前端 + Java 后端 + MySQL）。

---

## 1. 整张图（先看这个）

```text
微信小程序页面 (pages/)
        │  HTTP
        ▼
utils/api.js  →  http://127.0.0.1:8080
        │
        ▼
server/（Spring Boot）
        │  spring.datasource
        ▼
MySQL 库 gz199（8 张表）
```

- **前端**：`pages/`、`components/`、`utils/` … 跑在微信开发者工具里  
- **后端**：`server/`，端口 **8080**  
- **数据库**：本机 MySQL，库名 **gz199**

## 4. Spring Boot 是在哪里连上数据库的？

不是某行「手写 connect」魔法，而是 **配置 + 依赖 + 自动装配** 三步。

### 第 1 步：依赖（告诉项目「我要用 MySQL」）

文件：`server/pom.xml`

```xml
spring-boot-starter-jdbc   <!-- Spring 的 JDBC 能力 -->
mysql-connector-j          <!-- MySQL 官方驱动 -->
```

有了这两样，Spring Boot 才会去读数据源配置并建连接池。

### 第 2 步：连接参数（真正写「连哪台库」的地方）

文件：**`server/src/main/resources/application.yml`**

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/gz199?...
    username: root
    password: ${DB_PASSWORD:}      # 密码从环境变量读，不写死在仓库里
    driver-class-name: com.mysql.cj.jdbc.Driver
```

含义通俗讲：

| 配置项 | 意思 |
|--------|------|
| `127.0.0.1:3306` | 本机 MySQL |
| `gz199` | 数据库名 |
| `username: root` | 用户名 |
| `password: ${DB_PASSWORD:}` | 启动前设置环境变量 `DB_PASSWORD` |
| `driver-class-name` | 用 MySQL 驱动 |

密码怎么设？本地常见两种：

1. 双击 **`重启后端.bat`**（会从 `server/start-dev.ps1` 读出密码）  
2. 或手动：

```powershell
$env:DB_PASSWORD = "你的密码"
```

### 第 3 步：启动时自动连上

文件：`server/src/main/java/com/gz199/Gz199Application.java`

```java
@SpringBootApplication
public class Gz199Application {
  public static void main(String[] args) {
    SpringApplication.run(Gz199Application.class, args);
  }
}
```

启动后 Spring Boot 会：

1. 读 `application.yml` 里的 `spring.datasource`  
2. 创建 `DataSource`（连接池）  
3. 你的类只要注入 `DataSource` / `JdbcTemplate` 就能查库  

业务里真正「用库」的例子：

- `MysqlSchoolRepository`：构造函数注入 `DataSource`，用 `JdbcTemplate` 执行 SQL  
- `DbHealthController`：`SELECT VERSION()` 测连通  
- `SchoolDataController`：详情优先走 MySQL（表里有数据时）

### 4.1 一句话记住

> **连哪台库、哪个用户：看 `application.yml` 的 `spring.datasource`。**  
> **密码：环境变量 `DB_PASSWORD`（重启脚本会帮你设）。**  
> **谁去查表：`MysqlSchoolRepository` 等 Java 类。**

## 5. 怎么确认已经连上了？

后端启动成功后，浏览器打开：

1. http://127.0.0.1:8080/api/health  
   - 看 `mysqlReady: true`（有院校数据后）  
2. http://127.0.0.1:8080/api/db/health  
   - 看 `ok: true`、`mysqlVersion`、各表行数
