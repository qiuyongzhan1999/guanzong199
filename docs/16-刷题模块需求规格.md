# 16 · 刷题模块需求规格（管综 + 英语二）

> **用途：** 后续按本文档 **分阶段、一步步开发与验收**。  
> **来源：** [DeepSeek 分享讨论](https://chat.deepseek.com/share/xelnf7c4ns2purv3jk)（2026-09-22）+ 本仓库既有产品范围（文档 01 / 04 / 08 / 09 / 10）。  
> **技术约束：** 前端 uni-app Vue3；后端 Java Spring；UI 只许 `styles/edu-theme.js` + `styles/edu-ui.scss`（禁止紫渐变、直角灰边、局部乱写 hex）。

---

## 0. 一句话目标

做出 **管综刷题（数学 · 逻辑）** 与 **英语二刷题（阅读 · 完形等）** 的完整练习闭环：**选题 → 做题 → 看解析 → 收藏 → 错题册 → 薄弱点可见**，首页入口要「想点进去刷」，而不是冷冰冰的工具壳。

---

## 1. 背景与现状

| 项 | 说明 |
|----|------|
| 已有 | 首页「刷题开练」两张入口卡（管综 / 英语二），目前多为「还没开放」占位 |
| 已有 | 择校、AI 作文批改已上线或可跑通 |
| 缺口 | 无题库页、答题页、收藏、错题册、答题统计 |
| 讨论诉求 | 炫酷实用；收藏 + 错题册；以及用户没想到的增值能力 |

---

## 2. 范围

### 2.1 必做（本需求文档主线）

1. 管综刷题（数学 / 逻辑，可按知识点、难度筛）
2. 英语二刷题（阅读 / 完形等题型，可按题型筛）
3. 答题与解析
4. 收藏 / 取消收藏
5. 错题册（进入、重做、标记已掌握）
6. 答题记录与基础正确率
7. 知识点掌握度（用于雷达图数据，V1 可先接口+简单展示）

### 2.2 明确不做（本阶段）

- 完整在线机考 / 倒计时正式模考考场
- 视频「刷课」网课播放器（可预留入口，不进本期）
- 复杂 VIP 兑换体系（积分兑换可 V3 再谈）
- 伪造官方分数线 / 官方题库版权不清的内容上线

### 2.3 题库版权前提（阻塞项）

开发联调可用 **自备样例题**；上线前必须确认题目来源合法（自编 / 授权 / 公开可引用）。无题库内容则只交付壳与接口契约。

---

## 3. 用户故事（验收用语）

1. 作为考生，我可以从首页进入管综或英语二刷题，并开始做题。
2. 作为考生，我提交答案后能立刻看到对错与解析。
3. 作为考生，我可以把题目收藏，之后在收藏夹里重做。
4. 作为考生，我答错的题会进入错题册，我可以重做并标记「已掌握」。
5. 作为考生，我能看到自己在若干知识点上的正确率（薄弱项）。

## 4. 信息架构与页面

对照文档 04，落地以下页面（路径可微调，但职责不变）：

| 页面 | 建议路径 | 职责 |
|------|----------|------|
| 刷题首页 | `pages/practice/index` | 选科目 / 题型 / 模式；入口到收藏、错题、统计 |
| 答题页 | `pages/practice/quiz` | 沉浸式做题、收藏、看解析、下一题 |

| 错题册 | `pages/practice/wrong` | 错题列表 / 卡片复习、标记掌握 |

首页 `pages/index`：「刷题开练」两张卡改为 **可进入** `practice/index`，并透出今日待刷 / 错题数 / 正确率（有数据才显示，无数据给空态文案）。

## 5. UI / UX 规格（炫酷但守 edu 规范）

> DeepSeek 原文建议「蓝紫 / 翠绿玻璃拟态」。**本项目改写为：** 管综用 `signal` 蓝系，英语用 `good` 绿系，强调/错题用 `heat`；组件用 `edu-page` / `edu-card` / `edu-chip` / `StatRow` 等，动画克制、可读优先。

### 5.1 首页「刷题开练」卡

- 管综卡：signal 浅色渐变底 + 数据透出（今日待刷、错题复习、正确率）
- 英语卡：good 浅色渐变底 + 同上
- 底部快捷：收藏 / 错题本 / 练习记录（小入口，不抢主按钮）
- 点击主区域进入刷题首页；点击快捷进对应列表
- 微动效：按下缩放（`:active`），禁止花哨全屏粒子

### 5.2 答题页（核心体验）

| 元素 | 要求 |
|------|------|
| 顶栏 | 科目 + 题号进度（如 3/20）；可选简单进度条（答对偏 good，答错偏 heat，勿做成重度游戏血条） |
| 题干 | 清晰排版；长文（阅读）可折叠「展开全文」 |
| 选项 | 大点击区；选中 `edu-chip on` 态；提交后正确 good、错误 heat |
| 收藏 | 右上角星标，即时 toggle |
| 解析 | 默认折叠；展开分层：**破题思路 → 详解 → 知识点**（字段没有则隐藏该层） |
| 底部 | 上一题 / 下一题；未作答可「交卷本轮」 |
| 反馈 | 答对轻提示；答错可短震动（真机 `uni.vibrateShort`，可配置开关） |

### 5.3 错题册 / 收藏

- **列表优先**（稳定、易开发）；「卡片滑动复习」作为 V1.1 增强，不挡主线
- 标签：按知识点 / 科目筛选（`edu-chip`）
- 错题标记「已掌握」后默认移出「未掌握」列表，可在「已掌握」里找回
- 重做正确：更新掌握度；可选短暂成功态（勿强制碎裂特效）

## 6. 功能规格

### 6.1 刷题模式（V1）

| 模式 | 说明 |
|------|------|
| 顺序练习 | 按题库顺序取题 |
| 随机练习 | 随机抽题 |
| 专项突破 | 按知识点 / 题型筛选后练习 |
| 错题重做 | 从错题册进入的练习会话 |

可选后期：历年真题卷（需题库带 `year` / `paper` 字段）。

### 6.2 收藏

- 登录用户可对任意题收藏 / 取消
- 收藏夹支持按科目筛选
- 未登录：引导登录（与现有「我的」登录一致）

### 6.3 错题册

- 答错自动入库；`wrong_count` 累加；更新 `last_wrong_at`
- 答对且用户点「已掌握」→ `status=已掌握`
- 列表可按错误次数、知识点、最近错误时间排序

### 6.4 统计

- 汇总：总答题数、正确率、今日答题数
- 分知识点：`total` / `correct` / `mastery_rate`
- 前端雷达图：V1 可用简单条形/多维列表代替；V1.1 再上雷达图组件（色取 `EDU.chart`）

## 7. 数据模型（MySQL）

> 可在文档 13 增补正式 DDL；以下为需求级字段。

### 7.1 `questions` 题库

| 字段 | 类型建议 | 说明 |
|------|----------|------|
| id | BIGINT PK | |
| subject | VARCHAR | `guanzong` / `english` |
| type | VARCHAR | 数学 / 逻辑 / 阅读 / 完形 … |
| knowledge_point | VARCHAR | 知识点 |
| content | TEXT | 题干（可含简单富文本约定） |
| options | JSON | `[{key,text}]` |
| answer | VARCHAR | 如 `B` 或多选约定 |
| analysis | TEXT | 详解 |
| analysis_idea | TEXT | 破题思路（可空） |
| analysis_kp | TEXT | 知识点溯源（可空） |
| difficulty | TINYINT | 1–5 |
| year | INT | 可空 |
| status | TINYINT | 上下架 |
| created_at / updated_at | DATETIME | |

### 7.2 `user_answers` 答题记录

`id, user_id, question_id, user_answer, is_correct, time_spent_ms, mode, created_at`

### 7.3 `user_favorites` 收藏

`id, user_id, question_id, created_at`（唯一索引 user+question）

### 7.4 `user_wrong_questions` 错题

`id, user_id, question_id, wrong_count, last_wrong_at, status(0未掌握/1已掌握), updated_at`（唯一索引 user+question）

### 7.5 `user_knowledge_stats` 知识点掌握

`user_id, knowledge_point, subject, total, correct, mastery_rate, updated_at`（唯一 user+subject+kp）

## 8. API 契约（后端）

统一前缀建议：`/api/practice/...`；需登录的接口走现有鉴权。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/practice/questions` | 筛题：subject、type、knowledge_point、difficulty、mode、page |
| GET | `/api/practice/questions/{id}` | 单题详情（答题中可脱敏答案；提交后再返解析——或提交接口一并返回） |
| POST | `/api/practice/questions/submit` | body: questionId, answer, timeSpent；回写错题/统计；返回 isCorrect + analysis* |
| POST | `/api/practice/favorites/toggle` | body: questionId；返回 favorited |
| GET | `/api/practice/favorites` | 收藏列表 |
| GET | `/api/practice/wrong-questions` | 错题列表；query: status、subject、sort |
| POST | `/api/practice/wrong-questions/master` | 标记已掌握 |
| GET | `/api/practice/stats/overview` | 总览：正确率、今日、错题数等 |
| GET | `/api/practice/stats/knowledge` | 雷达/薄弱项数据 |

错误码与现有 API 风格对齐；空列表返回 `[]`，不要 404。

## 9. 「杀手锏」功能（分期，不阻塞 V1）

来源分享讨论，按投入产出排序：

| 优先级 | 功能 | 说明 | 建议版本 |
|--------|------|------|----------|
| P1 | AI 错题追问 | 解析下「继续问」；基于本题上下文答疑 | V2 |
| P1 | 变式题生成 | 根据错题生成 1–3 道同类题，做对才算掌握 | V2 |
| P1 | 薄弱项定向卷 | 点最弱知识点 → 生成 N 题专项 | V2 |
| P2 | 每日错题推送 | 订阅消息 + 遗忘曲线抽 5 题 | V3 |
| P2 | 英语长难句解剖 | 框选句子 → 成分/译文/词汇 | V2–V3 |
| P3 | 成就徽章 | 连续打卡等 | V3 |
| P3 | 逻辑画图板 | 手绘草稿；AI 识图反馈属高难 | V3 研究项 |

> **已砍掉：** 考友 PK / 排行榜 / 好友对战（不做）。

**V2 AI 约束：** Prompt 进 `server/src/main/resources/skills/`；Key 只放服务端；计次可与作文批改共用额度策略。

## 10. 开发阶段（严格按序，一步步做）

每完成一阶段，打勾并做「完成标准」验收后再进入下一阶段。

### 阶段 A · 题库与后端骨架

- [x] 编写并执行刷题相关 DDL（并入文档 13 或独立 SQL）
- [x] 导入不少于 **30** 道样例题（管综数学/逻辑、英语各有覆盖）→ 当前先落地管综 **15** 道样例
- [x] 实现题目列表 / 详情 / 提交答题 API
- [x] 单元或接口自测：提交正确/错误会写 `user_answers`

**完成标准：** Postman/前端 mock 可拉题并提交，库中有记录。

### 阶段 B · 前端刷题闭环

- [x] `pages.json` 注册 practice 相关页
- [x] 刷题首页：科目、模式、筛选
- [x] 答题页：选项、提交、解析、上一题/下一题
- [x] 首页「刷题开练」接真入口
- [x] UI 符合 edu-ui（管综 signal / 英语 good）

**完成标准：** 真机可完整做完一轮 5 题并看到解析。

### 阶段 C · 收藏 + 错题册

- [x] favorites toggle + 列表页
- [x] 错题自动入库 + 列表 + 重做 + 标记掌握
- [x] 答题页星标收藏

**完成标准：** 收藏与错题列表数据与库一致；掌握后默认不再出现在「未掌握」。

### 阶段 D · 统计与首页透出

- [x] overview + knowledge stats API
- [x] 统计页（列表或简易图）
- [x] 首页卡片显示待刷/错题/正确率

**完成标准：** 刷一批题后首页数字变化正确。

### 阶段 E · V2 AI 赋能（可选排期）

- [ ] AI 追问接口 + 答题页入口
- [ ] 变式题生成 + 练习会话
- [ ] 薄弱项一键出卷

**完成标准：** 至少 1 个 AI 能力可演示；有失败降级文案。

### 阶段 F · V3 留存与社交（可选）

- [ ] 订阅消息每日错题包
- [ ] （可选）徽章 / 长难句 / 画图板立项评审后再做

> **不做：** 考友 PK、排行榜、好友对战。
