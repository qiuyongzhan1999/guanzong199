# 05 · 功能模块详解

每个模块写清：目标、页面、接口职责、权限。实现时按模块开分支/按阶段勾选。

---

## M1 · 账号与登录

| 项 | 说明 |
|----|------|
| 目标 | 微信静默/一键登录，拿到稳定 `userId` |
| 流程 | `wx.login` → 服务端 `code2session` → 发自有 JWT/session |
| 权限 | 浏览可匿名；收藏、批改、购买需登录 |
| 页面 | 我的头部、各业务触发登录弹层 |

---

## M2 · 首页运营

| 项 | 说明 |
|----|------|
| Banner | CMS 或后台配置图+跳转链接 |
| 宫格 | 本地配置即可，后期可远程下发 |
| 统计 | 点击事件上报（自建或微信分析） |

---

## M3 · 院校库与智能择校

完整交互与字段来源见 [11-智能择校页面与数据来源.md](./11-智能择校页面与数据来源.md)。

| 项 | 说明 |
|----|------|
| 院校名片 | 来自研招网院校库；导入表 `data/择校院校_首批导入.xlsx` |
| 列表 / 搜索 | 分页、校名、省份、双一流/自划线；列表**不展示**无来源的学费分数 |
| 智能择校 | 专业（必选）+ 层次 + 地区 → 过滤「已核验招该专业」的学校 |
| 详情 | 按「学校+专业+就读方式+年份」展示培养信息与招录；每块带 `source_url` |

## M4 · 备考体系（基础→冲刺→真题）

| 项 | 说明 |
|----|------|
| 内容树 | 科目 → 阶段 → 章节/试卷 → 正文 |
| 正文形态 | 富文本、图片、音视频链、附件 |
| 真题 | 按年归档；支持「仅目录免费」 |
| 学习进度 | 记录看到哪一章（登录用户） |
| 权限 | `content.access_level`: free / vip / purchase |

**管综栏目建议目录种子：**

```
数学
  基础：算术/代数/几何/数据分析入门
  强化：高频题型专题
  冲刺：易错与速度训练
  真题：2015–2026 分年
逻辑
  基础：概念与形式逻辑入门
  强化：论证评价/假设/支持削弱…
  冲刺：套题节奏
  真题：分年
写作
  基础：题型认知与结构模板
  强化：常见漏洞类型 / 论说文素材
  冲刺：限时训练
  真题：分年（可与 AI 批改打通「去批改」按钮）
```

## M5 · AI 作文批改

| 项 | 说明 |
|----|------|
| 输入 | 文本为主；图片 OCR 二期 |
| 输出 | JSON 结构化：分项分、总评、问题列表、修改建议、范文片段 |
| 配额 | 按「次」扣减；VIP 送次或包月不限（慎用，防亏） |
| 防刷 | 同文 hash 去重、长度上下限、频率限制、敏感词 |
| 成本 | 见 06 文档；失败不扣次或可重试 1 次 |

## M6 · VIP / 订单 / 兑换

| 项 | 说明 |
|----|------|
| 商品 | 会员时长、批改次卡、组合包 |

| 展示 | 我的页 + VIP 中心 |

详见 07 文档。

## M7 · 获客与服务

| 项 | 说明 |
|----|------|
| 1v1 | 表单（微信、目标院校、分数预估）→ 企微跟进 |

## M8 · 管理后台（你自己用，可很简陋）

首版可用：Excel 导入院校 + 简单 Admin（或甚至直接改数据库）。

**至少要能：**

- 上下架内容、改 VIP 标识
- 生成兑换码、查订单
- 看 AI 调用量与成本
- 给用户手工开通/延期 VIP（客服补单）
